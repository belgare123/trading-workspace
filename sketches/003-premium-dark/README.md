## Variant: Premium Dark

### Design stance
Refined, institutional-grade fintech interface — polished spacing, subtle gradients, breathing indicators, and elevated cards with soft shadows.

### Key choices
- **Layout**: Same as reference, slightly wider and more spacious
- **Typography**: Inter (body) + Playfair Display (reserved for headings) + JetBrains Mono (data)
- **Color**: Deepest #05070a background, card backgrounds with 1px semi-transparent borders
- **Interaction**: Animated breathing dots on stat indicators (`@keyframes breathe`), glowing pulse on live events, subtle hover lift
- **Details**: Gradient accent on price and center number, logo mark with shadow, 3px blue active left border

### Trade-offs
- **Strong at**: Professional polish, trust signals, readability
- **Weak at**: Slightly heavier page weight, less "edgy" than Glass or Terminal

### Best for
Production trading platform, institutional users, multi-role teams (traders + devs + ops)
