# Known Limitations — RC1

> **Дата:** 2026-07-23
> **Платформа:** Trading Workspace (workspace-ui)
> **Контекст:** Production Candidate RC1
> **Назначение:** Прозрачная документация осознанных ограничений RC1

---

## Принцип

Этот документ фиксирует **осознанные ограничения** Production Candidate RC1.
Они не являются дефектами — это решения о scope, принятые для фокусировки Stage 1.
Каждое ограничение имеет план устранения в одном из следующих релизов.

---

## Ограничения

### L-01 — Docker-сценарии не сертифицированы

| Поле | Значение |
|------|----------|
| **Область** | Deployment |
| **Влияние** | Развёртывание вручную, не через Docker |
| **Причина** | Docker не является обязательным для Stage 1 (один символ, одна стратегия) |
| **План** | Сертифицировать Docker-сценарии после Stage 1 |
| **Tracker** | B1-01 (Runbook section 4-5: NOT TESTED) |

### L-02 — Горячая ротация секретов (hot-reload)

| Поле | Значение |
|------|----------|
| **Область** | Operations |
| **Влияние** | Смена API-ключа требует restart процесса |
| **Причина** | SecretsProvider read-only после start. Hot-reload требует архитектурного решения |
| **План** | RC2: поддержка hot-reload для API keys |
| **Tracker** | Configuration freeze, A1 |

### L-03 — 7-дневный capacity run не завершён

| Поле | Значение |
|------|----------|
| **Область** | Longevity |
| **Влияние** | Нет подтверждения стабильности > 7 дней |
| **Причина** | 7-дневный тест перенесён на Stage 2 как целевой, а не блокер RC1 |
| **План** | Stage 2: запуск 7-дневной кампании |
| **Tracker** | B2-08 |

### L-04 — Масштабирование на несколько бирж

| Поле | Значение |
|------|----------|
| **Область** | Architecture |
| **Влияние** | Поддерживается только Bybit |
| **Причина** | Архитектура рассчитана на single-exchange для RC1 |
| **План** | Post-RC1: BrokerAdapter template для новых бирж |
| **Tracker** | Архитектурное решение |

### L-05 — Prometheus endpoint не настроен локально

| Поле | Значение |
|------|----------|
| **Область** | Observability |
| **Влияние** | Метрики доступны через state/health/metrics-history, но не через Prometheus |
| **Причина** | Prometheus endpoint будет настроен на VPS при Stage 1 деплое |
| **План** | Stage 1 деплой: настроить OpenTelemetry → Prometheus → Grafana |
| **Tracker** | B2-05 |

### L-06 — Реальный ордер на MainNet не отправлен

| Поле | Значение |
|------|----------|
| **Область** | Trading |
| **Влияние** | PAT 15/15 подтверждён через PaperBroker, не через реальный exchange |
| **Причина** | Реальный ордер будет исполнен только при Stage 1 |
| **План** | Stage 1: первый ордер на MainNet с минимальным размером |
| **Tracker** | PAT-01 |

### L-07 — SQLite не масштабируется горизонтально

| Поле | Значение |
|------|----------|
| **Область** | Data |
| **Влияние** | SQLite — single-file database, не поддерживает кластеризацию |
| **Причина** | Для Stage 1 (один символ, ~100 событий/день) SQLite более чем достаточен |
| **План** | Stage 3: обсудить миграцию на PostgreSQL для multi-exchange |
| **Tracker** | B2-02 |

### L-08 — Отсутствует Web UI для мониторинга

| Поле | Значение |
|------|----------|
| **Область** | Observability |
| **Влияние** | Мониторинг через Telegram + CLI + Grafana |
| **Причина** | Web UI — отдельная подсистема, не в scope RC1 |
| **План** | Post-RC1: обсудить web dashboard |

---

## Ограничения за рамками RC1 (не планируются)

| Ограничение | Обоснование |
|-------------|-------------|
| Multi-user access | Single-user платформа |
| Mobile app | Не в scope |
| fiat on/off ramp | Только USDT |
| Machine learning signals | SmaCross + Rule-based достаточно для Stage 1 |
| High-frequency trading | Event-driven, не HFT |
| Dark pool / OTC | Только биржевые ордера |
