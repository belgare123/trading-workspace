# Sprint 6.6.5 — Gateway Runtime Certification

> **Goal:** Prove GatewayRuntime maintains architectural invariants under all transport failure modes.
> **Architecture:** State machine with 4 transport states × 3 transport dimensions = matrix certification.
> **Dogma:** No `if (chaosEnabled)` — transport failures arrive via IWebSocketFactory DI only.

## Architecture

```
GatewayRuntime (state machine)
  ├── REST (FailureInjector scope: ORDERS, MARKET_DATA)
  ├── Public WS (FailureInjector scope: PUBLIC_WS)
  └── Private WS (FailureInjector scope: PRIVATE_WS_*)
        │
  HealthAggregator ← ChaosTraceRuntime ← RuntimeTelemetry → EventJournal
        │
  Circuit Breaker → Safe Mode → Recovery
```

## Block 1: Gateway State Machine

**Add state machine to GatewayRuntime:**
- States: `Healthy`, `Degraded`, `Disconnected`
- Track per-transport: `restOnline`, `publicWsOnline`, `privateWsOnline`
- Transition table with forbidden transitions:
  - Healthy → (transport loss) → Degraded
  - Degraded → (last transport lost) → Disconnected
  - Disconnected → (reconnect) → Healthy (after full recovery)
  - No: Healthy → Disconnected directly
  - No: Degraded → Healthy without recovery
- HealthAggregator registration: gateway health reflects current state
- Telemetry: record state transitions
