## Semantic Event Categories (new for 6.6.4)

Events are NOT grouped by Bybit WS package. They are grouped by **semantic domain** so chaos can be targeted per category:

| Category | Scope | Events | Criticality |
|----------|-------|--------|-------------|
| **Execution** | `PRIVATE_WS.EXECUTION` | order ACK, cancel ACK, replace ACK | **highest** — must never lose ACK |
| **Order** | `PRIVATE_WS.ORDER` | order updates, status changes | **high** — strict FSM |
| **Fill** | `PRIVATE_WS.FILL` | fill events, trades | **high** — idempotency required |
| **Position** | `PRIVATE_WS.POSITION` | position updates | **high** — must match REST after reconnect |
| **Wallet** | `PRIVATE_WS.WALLET` | balance/equity changes | **medium** — divergence detection |

The `FailureInjectionScope` enum gains a hierarchical structure:
```typescript
enum FailureInjectionScope {
  REST,
  PUBLIC_WS,
  PRIVATE_WS,          // umbrella — affects all private WS
  PRIVATE_WS_EXECUTION, // category-specific
  PRIVATE_WS_ORDER,
  PRIVATE_WS_FILL,
  PRIVATE_WS_POSITION,
  PRIVATE_WS_WALLET,
  PRIVATE_WS_ACCOUNT,
}
```

A rule scoped to `PRIVATE_WS` matches any private WS event. A rule scoped to `PRIVATE_WS_EXECUTION` matches only execution events. This enables selective chaos: `packet_loss → EXECUTION` but `Wallet → untouched`.

**Default classifier (Bybit v5 private WS):**

**Files:**

- Test: `src/runtime/chaos/__tests__/WebSocketFactory.test.ts` — verify factory creates PrivateWebSocket

**Add to WebSocketFactory.ts:**

```typescript
export class PrivateWebSocketFactory implements IWebSocketFactory {
  constructor(
    private injector: FailureInjector,
    private observer?: IFailureObserver,
    private classifiers?: CategoryClassifier[]
  ) {}

  createWebSocket(url: string): WebSocket {
    const ws = new PrivateWebSocket(url, this.injector, this.observer, this.classifiers)
    ws.connect()
    return ws as unknown as WebSocket
  }
}
```
