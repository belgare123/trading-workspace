## Platform Invariants v1.0 (cross-cutting)

Создаётся параллельно с PRR как единый источник истины.
**Артефакт:** `docs/architecture/platform-invariants-v1.0.md`

**Примеры инвариантов:**
- Один Fill применяется ровно один раз (idempotency)
- Replay всегда детерминирован (hash(state) = const)
- Sequence strictly increasing (no gaps, no rewinds)
- Wallet never negative
- Position after replay ≡ position before replay
- No forbidden gateway state transitions
- Circuit Breaker: NOT (Closed AND Degraded)
- Snapshot sequence ≥ last applied event
- ChaosTrace: every injection has a corresponding trace event
- SLO: recovery <5s, replay <2s, wallet sync <1s
